The audit has localized the closed-system drift strongly enough to justify a

**V3 remains on HOLD until that fix is implemented and revalidated.**

# 1. First-divergence localization

The audit decomposes the production timestep into:

\`\`\`text
S0 -> collision -> S1 -> F.fill(0) -> S2
   -> streaming1 -> S3
   -> Boundary_condition -> S4
   -> streaming3 -> S5
   -> Boundary_condition_psi -> S6
\`\`\`

The first accumulating imbalance appears at:

\[
\boxed{S0\rightarrow S1:\ \mathrm{collision}()}
\]

Two independent collision-channel identities fail:

- **J1** — total-distribution zeroth moment;
- **J7** — colour-population zeroth moment.

The downstream transport identities are clean in the tested closed cases:

- J3 streaming / bounce-back: zero;
- J5 total copy: zero;
- J8 colour consume: zero;
- J9 next-step closure: zero.

Thus the V2 drift is not primarily generated by wall bounce-back or the
subsequent streaming operations.

---

# 2. Total-distribution channel: diagnosis accepted

The frozen solver stores:

\[
\mathrm{inv\_M}
=
\mathrm{float32}(M^{-1}).
\]

For exact zeroth-moment conservation the stored inverse must satisfy:

\[
\sum_s (\mathrm{inv\_M})_{s0}=1
\]

and for every non-density moment \(l>0\),

\[
\sum_s(\mathrm{inv\_M})_{sl}=0.
\]

Measured from the solver's actual f32 table:

\[
\sum_s(\mathrm{inv\_M})_{s0}
=
1+1.490116119\times10^{-8}.
\]

The predicted systematic scale:

\[
1.4901\times10^{-8}/step
\]

agrees with:

- C3 GPU: \(1.556\times10^{-8}/step\);
- C3 CPU: \(1.517\times10^{-8}/step\);
- V2 production population channel: approximately
  \(1.53\times10^{-8}/step\).

This agreement is too close to treat the matrix defect as incidental.

The total-distribution diagnosis is accepted.

---

# 3. Colour channel: separate conservation closure

The audit also establishes an independent colour-population drift inside
\`collision()\`.

This should **not** be collapsed conceptually into the \`inv_M\` defect.

The two channels use different arithmetic paths:

### Total channel

\[
F
\rightarrow
m=M F
\rightarrow
m^\*
\rightarrow
f=\mathrm{inv\_M}\,m^\*.
\]

### Colour channel

\[
\rho_r,\rho_b
\rightarrow
g_r^{eq},g_b^{eq}
\rightarrow
\mathrm{recolor}
\rightarrow
rhor,rhob.
\]

The current evidence indicates:

- equilibrium-distribution pair/sum rounding is the dominant colour
  zeroth-moment term;
- recoloring pair arithmetic is much smaller;
- the colour drift is slower than the total-distribution drift but still
  systematic in the active C3 case.

Therefore the fix task must treat **two zeroth-moment invariants**:

\[
\sum_q f_q^{post}
=
m_0^{pre}
\]

and separately:

\[
\sum_q g_{r,q}^{post}
=
\rho_r^{pre},
\qquad
\sum_q g_{b,q}^{post}
=
\rho_b^{pre}.
\]

A fix that corrects only \`inv_M\` is incomplete.

# 4. Why PASS_BOUNDED_FLOOR is rejected

C0/C2 demonstrate a one-time bounded f32 initialization/relaxation offset:

\[
\sim3.43\times10^{-7}
\]

followed by a bit-exact fixed point.

That behaviour alone would be compatible with a numerical floor.

C3 is different:

\[
\Delta M_f/M_0
=
7.46\times10^{-5},
1.52\times10^{-4},
2.31\times10^{-4},
3.10\times10^{-4}
\]

at 5k / 10k / 15k / 20k steps.

The fitted slope is:

\[
1.556\times10^{-8}/step
\]

with:

\[
R^2\approx0.9999
\]

and 100% late-step positive sign bias on both GPU and CPU.

This is an accumulating deterministic arithmetic bias, not a bounded floor.

# 5. Isolation-matrix interpretation

The C0–C3 matrix supports the localization:

- **C0 periodic single phase:** no accumulating drift after the short
  initialization transient;
- **C1 periodic two phase:** interface/non-equilibrium introduces drift,
  backend-dependent in the eventual quiescent realization;
- **C2 single phase + walls:** no accumulating drift;
- **C3 two phase + walls:** robust linear drift on both CPU and GPU.

The combination means:

- wall bounce-back is not sufficient to create the drift;
- persistent multiphase non-equilibrium is sufficient to keep the collision
  arithmetic bias active;
- atomic ordering alone cannot explain C3 because CPU and GPU reproduce the
  same sign and nearly the same total-channel rate.

The previous V2 review allowed a choice between:

# 7. Required solver-fix design

The fix task should test candidate implementations rather than immediately
promoting one.

## 7.1 Total-distribution candidates

At minimum compare:

### T1 — stored-matrix mass projection

Modify the stored f32 inverse transform so its column sums satisfy the exact
zeroth-moment constraints as closely as representable:

\[
\mathbf{1}^T\mathrm{inv\_M}
=
(1,0,\ldots,0).
\]

This is attractive because it attacks the matrix-level identity directly.

### T2 — local post-reconstruction zeroth-moment correction

After reconstructing the 19 populations, enforce:

\[
\sum_q f_q=m_0.
\]

The correction must be designed to preserve momentum exactly.

A rest-population correction is the smallest candidate because
\(\mathbf e_0=0\), but its effect on isotropic stress / pressure should be
checked rather than assumed harmless.

### T3 — f64 moment roundtrip reference

Use f64 matrix + f64 accumulator as a **reference implementation**, not the
default production choice unless performance and Taichi/GPU cost are acceptable.

The audit already shows that f64 accumulator + f32 matrix alone is
insufficient.

## 7.2 Colour-channel candidates

After equilibrium + recoloring, enforce independently:

\[
\sum_q g_{r,q}=\rho_r,
\qquad
\sum_q g_{b,q}=\rho_b.
\]

At minimum test a local zeroth-moment projection that preserves each colour's
momentum contribution.

A rest-population correction is a natural minimal candidate because it has
zero lattice velocity, but the regression suite must verify that it does not
change static contact angle / surface tension in a material way.

Do not spend effort "fixing recoloring" unless the candidate measurements
show recoloring itself materially violates the per-colour sum after the
equilibrium-sum error is removed.

# 8. Required fix acceptance hierarchy

A solver-fix candidate should not be accepted merely because total mass drift
becomes smaller.

It must pass, in order:

## Level F0 — exact local conservation identities

For representative C0–C3 nodes/steps:

\[
|\sum f-m_0|
\]

and

\[
|\sum g_r-\rho_r|,
\quad
|\sum g_b-\rho_b|
\]

must drop to the expected f32 representation floor with no systematic sign
bias.

## Level F1 — long-horizon closed-system drift

C3 20k / 60k extrapolated drift must improve by at least one order of
magnitude relative to the current:

\[
1.56\times10^{-8}/step.
\]

Target engineering level:

\[
r_M\lesssim2\times10^{-9}/step
\]

for both total and colour channels, unless a defensible lower floor is measured.

## Level F2 — existing solver regressions

Re-run:

- Level A;
- Compute_C;
- Poiseuille;
- Laplace;
- contact angle;
- postprocessing.

No existing acceptance band may be weakened.

## Level F3 — V1c scientific regressions

Re-run or reproduce:

- static slit calibration;
- \(a_{26}\);
- \(a_{40}\);
- pressure-band diagnostics.

The conservation fix must not create a new hydraulic/wetting bias.

## Level F4 — V2 regression

Re-run V2 bilateral case:

- mirror symmetry;
- topology;
- trapped cluster;
- density guardrail;
- mass drift.

The expected improvement is conservation only; V2 qualitative physics should
remain unchanged.
